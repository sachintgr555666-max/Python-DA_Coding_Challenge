# HR Employee Attrition – Python Data Analysis Day Challenge

## Project Overview

This repository contains the Google Colab notebooks for the Python Data Analysis Day Challenge using the **HR Employee Attrition** dataset.

## Notebooks

- `Day_01_NumPy_Arrays_Operations.ipynb` – NumPy arrays and operations
- `Day_02_Pandas_Basics.ipynb` – Pandas basics
- `Day_03_Data_Exploration_Wrangling.ipynb` – Exploration, cleaning and wrangling
- `Day_05_Matplotlib_Visualization.ipynb` – Matplotlib charts
- `Day_06_Seaborn_Plotly_Advanced.ipynb` – Advanced visualization
- `Day_07_Data_Cleaning_Statistics.ipynb` – Data cleaning and statistics
- `Day_08_Introduction_Web_Scraping_AI.ipynb` – Requests, web scraping and AI-assisted coding
- `Day_09_BeautifulSoup_Web_Scraping.ipynb` – BeautifulSoup extraction and DataFrames
- `Day_10_Final_Integration_HR_Analysis.ipynb` – Final report, visualizations, insights and recommendations

## Dataset

Main dataset: **HR Employee Attrition**

Place `HR-Employee-Attrition.csv` in the same Colab working directory before running the notebooks.

## Web Scraping

Days 8 and 9 use `requests` and `BeautifulSoup` with `https://books.toscrape.com/`, a practice website intended for scraping exercises.

The scraped book data is kept as supplementary external data because it has no legitimate common key with the HR employee records. A false row-level merge is intentionally avoided.

## How to Use in Google Colab

1. Open a notebook in Google Colab.
2. Upload `HR-Employee-Attrition.csv`.
3. Run the cells from top to bottom.
4. For Days 9–10, run Day 9 first if you want the scraped output available to Day 10.
5. Download the completed `.ipynb` file.
6. Upload the `.ipynb` and this `README.md` to GitHub.

## Key Skills Demonstrated

Python, NumPy, Pandas, Matplotlib, Seaborn, Plotly, Requests, BeautifulSoup, data cleaning, descriptive statistics, web scraping, data visualization and business insights.
